# ChainTwo

ChainTwo enables distributed, scalable microservices to manage concurrent transactions across a decentralized, auto-scaling chain.

With ChainTwo, you get a lightweight tool that stays out of your way.

**What you get**

- ChainTwo enables distributed, scalable microservices
- to manage concurrent transactions across
- a decentralized, auto-scaling chain

- python

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/ChainTwo.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
